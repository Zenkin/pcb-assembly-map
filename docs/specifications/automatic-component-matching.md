# PCB Assembly Map — алгоритм автоматического сопоставления

| Параметр | Значение |
| --- | --- |
| Статус | Согласованные требования, подготовленные к реализации |
| Версия | 1.0 |
| Дата фиксации | 25.07.2026 |

## 1. Назначение

Алгоритм сопоставляет ожидаемые посадочные места компонентов, полученные из Pick and Place, с найденными на изображении платы посадочными местами.

Сопоставление выполняется отдельно для каждой стороны платы. Основными признаками являются:

- сторона платы;
- расстояние между ожидаемым и найденным центрами;
- геометрия посадочного места: количество площадок, их относительные координаты и размеры.

Позиционное обозначение, тип и наименование компонента из BOM не используются для фильтрации геометрически неизвестных кандидатов.

## 2. Термины

- **Ожидаемое место** — компонент из Pick and Place с центром, стороной платы, углом поворота и, при наличии, ожидаемой геометрией.
- **Найденное место** — посадочное место, найденное на изображении платы, с центром, стороной и, при наличии, найденной геометрией.
- **Площадка** — элемент геометрии посадочного места с центром `(x, y)`, шириной `w` и высотой `h`.
- **Кандидат** — найденное место на той же стороне платы, центр которого попал в разрешённый радиус поиска.
- **Точное совпадение** — геометрия полностью укладывается в точные допуски.
- **Допустимое совпадение** — количество площадок и общий габарит совпадают, но отдельные параметры площадок вышли за точный допуск, не превысив `1,5 ×` точный допуск.
- **Неизвестная геометрия** — геометрия отсутствует хотя бы у одной стороны сравнения.
- **Неоднозначный результат** — однозначно выбрать одно найденное место невозможно.

## 3. Настраиваемые параметры

| Параметр | Значение |
| --- | ---: |
| Абсолютная часть точного допуска | `0,10 мм` |
| Относительная часть точного допуска | `5%` |
| Коэффициент допустимого отклонения | `1,5` |
| Радиус при отсутствии обеих геометрий | `5 мм`, настраиваемый |
| Точность сравнения равных стоимостей | `10⁻⁹` |
| Коэффициент радиуса по диагонали `k` | `1,5` |

## 4. Расчёт радиуса поиска

### 4.1. Ограничение по плотности

Для текущего ожидаемого места определяется ближайшее **другое ожидаемое место на той же стороне платы**.

- Текущее место исключается.
- Расстояние измеряется между ожидаемыми центрами.
- Если сосед найден, ограничение плотности:

`R_density = 0,5 × D_neighbor`

где `D_neighbor` — расстояние до ближайшего другого ожидаемого места.

- Если других ожидаемых мест на этой стороне нет, ограничение плотности не применяется.
- Расстояние до края платы радиус не ограничивает.

### 4.2. Базовый радиус

1. Если известна ожидаемая геометрия:

   `R_base = k × diagonal(expected_geometry)`

2. Если ожидаемая геометрия отсутствует, но известна геометрия проверяемого найденного места:

   `R_base = k × diagonal(found_geometry)`

3. Если геометрия отсутствует с обеих сторон:

   `R_base = R_default = 5 мм`

### 4.3. Итоговый радиус

Если ближайший сосед найден:

`R = min(R_base, R_density)`

Если соседей нет:

`R = R_base`

Кандидат входит в область поиска, если:

`distance(expected_center, found_center) ≤ R`

Граница радиуса включается.

## 5. Подготовка геометрии

Для сравнения известной геометрии:

1. Ожидаемая геометрия поворачивается на угол компонента из Pick and Place.
2. Ожидаемая и найденная геометрии приводятся к одной системе координат.
3. Центры обеих геометрий совмещаются.
4. После совмещения сравниваются относительные координаты и размеры площадок.

Абсолютное смещение найденного места относительно ожидаемого центра используется для отбора по радиусу, но не подмешивается в проверку относительной геометрии.

## 6. Предварительная проверка известной геометрии

Кандидат с известной геометрией может пройти геометрическую проверку только при выполнении обоих условий:

1. Количество площадок ожидаемой и найденной геометрии одинаково.
2. Общий габарит по каждой оси совпадает в исходном точном допуске:

   `T_bbox_x = 0,10 мм + 0,05 × expected_bbox_x`

   `T_bbox_y = 0,10 мм + 0,05 × expected_bbox_y`

   `|found_bbox_x - expected_bbox_x| ≤ T_bbox_x`

   `|found_bbox_y - expected_bbox_y| ≤ T_bbox_y`

Для уровня «допустимое» общий габарит не получает коэффициент `1,5`: он по-прежнему обязан укладываться в исходный точный допуск.

## 7. Допуски отдельных площадок

Для каждой ожидаемой площадки:

### 7.1. Допуски положения центра

`T_x = 0,10 мм + 0,05 × expected_footprint_bbox_x`

`T_y = 0,10 мм + 0,05 × expected_footprint_bbox_y`

Допуски положения считаются от общего габарита ожидаемого посадочного места по соответствующей оси.

### 7.2. Допуски размеров

`T_w = 0,10 мм + 0,05 × expected_pad_width`

`T_h = 0,10 мм + 0,05 × expected_pad_height`

Допуски размеров считаются от ширины и высоты соответствующей ожидаемой площадки.

## 8. Оптимальное сопоставление площадок

Между ожидаемыми и найденными площадками строится взаимно-однозначное соответствие.

Для пары ожидаемой площадки `e` и найденной площадки `f` стоимость равна:

`C(e, f) = |Δx| / T_x + |Δy| / T_y + |Δw| / T_w + |Δh| / T_h`

где:

- `Δx`, `Δy` — отклонения центров после поворота и совмещения геометрий;
- `Δw`, `Δh` — различия ширины и высоты;
- все четыре компонента имеют равный вес.

Стоимость полного назначения:

`C_total = Σ C(e_i, f_assignment(i))`

Выбирается взаимно-однозначное назначение с минимальной суммарной стоимостью.

Если два или более разных назначения имеют минимальные стоимости, отличающиеся не более чем на `10⁻⁹`, геометрия считается неоднозначной, а найденное место исключается из подходящих кандидатов.

Суммарная стоимость используется только для поиска оптимального назначения площадок. Класс геометрического совпадения определяется по отдельным нормированным отклонениям, а не по `C_total`.

## 9. Классификация геометрического совпадения

После оптимального назначения для каждой пары проверяются четыре нормированных отклонения:

- `|Δx| / T_x`;
- `|Δy| / T_y`;
- `|Δw| / T_w`;
- `|Δh| / T_h`.

### 9.1. Точное

Кандидат имеет класс **«точное»**, если каждое из четырёх отклонений каждой пары:

`normalized_deviation ≤ 1,0`

### 9.2. Допустимое

Кандидат имеет класс **«допустимое»**, если:

- каждое из четырёх отклонений каждой пары не превышает `1,5`;
- хотя бы одно отклонение больше `1,0`;
- количество площадок совпало;
- общий габарит остался в исходном точном допуске.

### 9.3. Неподходящее

Кандидат считается неподходящим, если выполнено хотя бы одно условие:

- различается количество площадок;
- общий габарит вышел за исходный точный допуск;
- хотя бы одно нормированное отклонение больше `1,5`;
- оптимальное назначение площадок неоднозначно.

### 9.4. Неизвестная геометрия

Кандидат получает класс **«неизвестная геометрия»**, если геометрия отсутствует у ожидаемого или найденного места либо у обоих.

Для такого кандидата используются только:

- совпадение стороны платы;
- попадание центра в рассчитанный радиус.

Позиционное обозначение, тип и наименование компонента из BOM в этой проверке не участвуют.

## 10. Выбор итогового кандидата

Приоритет классов:

`точное → допустимое → неизвестная геометрия`

Правила выбора:

| Набор кандидатов | Результат |
| --- | --- |
| Ровно один точный | Выбрать его |
| Несколько точных | Неоднозначный результат |
| Точных нет, ровно один допустимый | Выбрать его |
| Точных нет, несколько допустимых | Неоднозначный результат |
| Есть точный и один или несколько допустимых | Выбрать точный |
| Точных и допустимых нет, ровно один с неизвестной геометрией | Выбрать его как неуверенное совпадение |
| Точных и допустимых нет, несколько с неизвестной геометрией | Неоднозначный результат |
| Подходящих кандидатов нет | Компонент не распознан |

Расстояние до ожидаемого центра и суммарная стоимость геометрии не используются для разрешения ситуации, когда одного уровня достигли несколько кандидатов.

## 11. Рекомендуемые итоговые статусы

Алгоритм должен возвращать не только выбранное место, но и явный статус:

| Статус | Смысл |
| --- | --- |
| `matched_exact` | Однозначно выбрано точное совпадение |
| `matched_acceptable` | Точных нет; однозначно выбрано допустимое совпадение |
| `matched_uncertain_geometry` | Известных совпадений нет; выбран единственный кандидат с неизвестной геометрией |
| `ambiguous_exact` | Найдено несколько точных мест |
| `ambiguous_acceptable` | Точных нет; найдено несколько допустимых мест |
| `ambiguous_unknown_geometry` | Известных совпадений нет; найдено несколько мест с неизвестной геометрией |
| `unmatched` | Подходящих кандидатов нет |

Для диагностики полезно также возвращать:

- ожидаемое позиционное обозначение;
- сторону платы;
- ожидаемый и найденный центры;
- рассчитанные `R_base`, `R_density` и итоговый `R`;
- класс каждого кандидата;
- причину отбраковки кандидата;
- выбранное назначение площадок и `C_total`;
- максимальное нормированное отклонение;
- признак неуверенного совпадения.

## 12. Псевдокод верхнего уровня

```text
for each expected_footprint:
    same_side_candidates = found_footprints on expected_footprint.side
    neighbor = nearest other expected footprint on the same side
    density_limit = 0.5 * distance_to(neighbor), if neighbor exists

    evaluated = []

    for each found_footprint in same_side_candidates:
        base_radius =
            k * diagonal(expected_geometry), if expected geometry exists
            else k * diagonal(found_geometry), if found geometry exists
            else configured default radius

        radius =
            min(base_radius, density_limit), if neighbor exists
            else base_radius

        if center_distance > radius:
            continue

        if either geometry is missing:
            evaluated += UNKNOWN_GEOMETRY
            continue

        rotate expected geometry by Pick and Place angle
        align geometry centers

        if pad counts differ or bounding boxes exceed exact tolerance:
            continue

        solve minimum-cost one-to-one pad assignment

        if multiple minimum assignments differ by <= 1e-9:
            continue

        if every normalized deviation <= 1.0:
            evaluated += EXACT
        else if every normalized deviation <= 1.5:
            evaluated += ACCEPTABLE

    if count(EXACT) == 1:
        return matched_exact
    if count(EXACT) > 1:
        return ambiguous_exact

    if count(ACCEPTABLE) == 1:
        return matched_acceptable
    if count(ACCEPTABLE) > 1:
        return ambiguous_acceptable

    if count(UNKNOWN_GEOMETRY) == 1:
        return matched_uncertain_geometry
    if count(UNKNOWN_GEOMETRY) > 1:
        return ambiguous_unknown_geometry

    return unmatched
```

## 13. Коэффициент радиуса

Для формулы базового радиуса принято:

`R_base = 1,5 × diagonal`

Коэффициент `1,5` даёт запас на смещение центра, а ограничение радиуса половиной
расстояния до ближайшего ожидаемого соседа предотвращает чрезмерное расширение
области поиска на плотных участках платы.
